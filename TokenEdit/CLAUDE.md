# TokenEdit

How to build and test is in the root `CLAUDE.md`.

`TokenEdit`: a token (tag, recipient) box, as an e-mail's To: field (`CTokenEditCtrl`, window class `WC_TokenEdit`), `TKE`-prefixed C-style API (`TKETOKEN` with a mask, `TKESUGGESTION`, `TKECOLORS`, `TKEN_*`; internal names are `Tke*`), GDI-drawn. Tokens flow in wrapping lines (`TkeLayoutTokens` in `src/TokenEditModel.*`: a token wider than a line is cut to it) and the box grows to `SetLineLimits`' maximum (`TKEN_HEIGHTCHANGED`, sent when the tokens change, never from `WM_PAINT`: `Changed` lays out at once), then scrolls with a thin thumb. The user types in a real `Edit` (`m_Edit(this, 1)`, `ALT_MSG_MAP(1)`) placed in the flow: after the last token it takes the rest of the line, among the tokens (where the caret was clicked, `TkeDropIndex`) it's as wide as its text. A separator (",;" by default), Enter, or the focus leaving the control (not the edit giving it to the control, which keeps the typed text: `LeaveTyping`) makes the text tokens (`TkeSplit`: line breaks always separate, quotes keep a separator, a piece that's all one quoted string loses them); a paste is split the same way (`WM_PASTE`: a single-line edit keeps only the first line). Each new token goes through `TKEN_TOKENADDING` (`NMTKETOKEN`, with its source `TKEA_*`), which may refuse it (its text goes back into the edit, selected), rewrite it (`pszText` to the app's own string) or set its image, colors, tip and `TKEF_INVALID` (red, a wavy underline, `TkeWave`) or `TKEF_LOCKED` (no close button); `TKES_NODUPLICATES`, `SetMaxTokens`. `EM_SETSEL(-1, -1)` only deselects and leaves the caret where it was: `CaretToEnd`. Clicks select tokens (Ctrl, Shift; `TkeTokenList::Select`); the control takes the focus while tokens are selected (`d.focus` is the keys' token) and the arrows go along them and into and out of the typing area as one more item in the flow (`src/TokenEditKeys.cpp`; Up/Down by line, `TkeLineNeighbor`); Delete/Backspace and the close buttons remove through `TKEN_TOKENREMOVING`; Backspace at the text's start selects the token before. Ctrl+C/X/V (and `WM_COPY`/`WM_CUT`/`WM_PASTE`) copy tokens as text quoted where needed (`TkeJoin`), so pasting gives the same tokens back. Suggestions (`src/TokenEditSuggest.cpp`): the app's list (`AddSuggestion`, or replaced while `TKEN_GETSUGGESTIONS` is sent on each change), matched at the start, then a word's start, then anywhere with `TKES_SUGGESTINSIDE` (`TkeMatchText`), by the text or else the detail, leaving out the tokens already there; shown in a popup that doesn't take the activation (`TkeSuggestList`, `WS_EX_NOACTIVATE`, the edit passes it the keys), the match in bold, the first row hot so Enter or Tab picks it (`TKEA_SUGGESTION`), Alt+Down all of them. A double click or F2 puts a token back into text (`src/TokenEditEditing.cpp`, `TKEN_TOKENEDITING`): it's out of the list meanwhile, the first piece typed back gets its image, colors, tip and lParam (`TKEA_EDITED`), Escape puts it back, an emptied edit removes it. Selected tokens can be dragged (`TKES_NOREORDER`; a press on a selected token keeps the selection until it's a drag) with an insertion mark (`TkeDropMark`), `TKEN_TOKENSMOVED`. Undo/redo (`TkeHistory`, Ctrl+Z/Ctrl+Y; in the edit only with nothing typed) keeps whole token lists per user change (an edit is one step, from before the token came out); the API's changes clear it. Tooltips: one tool moved onto the hot token (its tip, or its text when cut) or close button (`SetCloseTip`). Like DiffView it follows WTLHelper's dark mode through `GetSysColor` and the registered `ThemeChanged` message; high contrast uses the system colors over the app's and the tokens' own, tokens framed, the hot one in the highlight color (`ForceHighContrast` for testing). MSAA (`src/TokenEditAccessible.cpp`): the box is a list of the tokens (list items named by their text, described by their tip and "Invalid", selected and focused as the control's, default action Edit) followed by the Edit's own object, which is named after the box through `IAccPropServices` (needs COM on the thread); the suggestions' popup is a list whose hot row is reported selected and focused as it moves (always: readers ask only after an event), default action Pick; actions are posted (`WM_TKE_ACCACTION`). The model is covered by `TokenEditTests`; `TokenEditDemo` (recipients from an address book and colored tags, which links WTLHelper on x64) is for checking by hand.
